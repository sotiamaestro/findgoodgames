## Note added after the first full run

NVIDIA's games page distinguishes Ready-to-Play titles from 2,200+ Install-to-Play titles (premium tiers). The catalog API returns both and no field we could find separates them, so the pipeline's GeForce NOW flag means "listed in NVIDIA's library".

## Decisions taken from this probe

1. **GeForce NOW comes from the GraphQL catalog, not the static file.** The static file still responds, so a naive check would have called it healthy; its `last-modified` and the missing 2024+ titles prove it is frozen. `optimized` is null for every game until NVIDIA exposes a flag again.
2. **Candidates come from Steam's own tag query, with SteamSpy and picks.json as additional seeds.** SteamSpy's tag endpoint only returns its top ~800 games per tag, which would hide exactly the small games this site is for. The Query endpoint returns every tagged game and the store record in the same response, so the "store data" stage costs about 30 requests instead of thousands.
3. **Exact review counts come from GetAppReviews with purchase_type=0 and languages=["all"]**, because that is the combination that reproduces the number on the store page. GetItems' summary is used to skip games that cannot pass the 100-review / 70% bar before spending a request on them.
4. **PCGamingWiki is read through wikitext, not Cargo.** Cargo is closed to anonymous callers. Page titles are tried in batches of 50 first, with a per-appid text search as the fallback.
5. **No Steam API key is required** for any endpoint used. `STEAM_API_KEY` is passed through when present but nothing depends on it.
